# Stable integration contract v1

**Current extension:** [Multiplayer lobbies and rematches](MULTIPLAYER.md) supersedes fixed-roster, p1-only ownership, immutable-start-only lifecycle and historical owner/path allocations below. These original contracts remain the compatibility baseline for historical rooms.

Setting: **Lantern Wake**, a drifting storm-beacon platform. Six keepers, five crew and one hidden saboteur. Room IDs/graph, characters, action names and rule defaults are in `shared/contracts.mjs`. No role in public character constants. Internal role strings are `crew` and `saboteur`. Starting room is bridge. Demo mode is explicitly labeled.

## Engine (Agent 2 / Core)

Own `server/engine/**`, `tests/engine*.test.mjs`, `docs/RULES.md`. Export from `server/engine/index.mjs`:

- `createMatch({id,mode='human',humanPlayerId='p1',now=Date.now(),seed,config={}})` returns serializable state. Mode `spectator` has six AI; human has p1 human. Engine may use seed for deterministic tests; production randomness must not derive hidden roles from public room IDs.
- `applyAction(state,playerId,action,now)` returns `{state,events,accepted,error?,duplicate?}`. No caller can change another player. Input state is not mutated. Envelope action has `id` (bounded unique request string), `type`, and only fields appropriate to type: move `roomId`; task `taskId`; eliminate `targetId`; report `bodyId`; say `text`; vote `targetId` (player ID or `skip`); sabotage/repair/meeting/wait have no extra required fields. Validate ALL input. Idempotency is per actor/request and remains persisted. Reuse of ID with different contents rejects.
- `tick(state,now)` returns `{state,events}` and handles deadlines/victory without browser activity. State version monotonically increments on actual changes. Apply/tick are synchronous and never call providers.
- `getPlayerView(state,playerIdOrNull,now)` returns exactly the safe shared view below. Null is public spectator; never returns full hidden state. AIs receive this same function with their own ID. `getReplay(state)` returns a fully attributed role-reveal event log ONLY when ended; before that return null or throw safe error.

View shape: `{matchId,version,phase,serverNow,deadlineAt,rooms,players,self,tasks,sabotage,meeting,outcome,events,availableActions}`. Players: `{id,name,color,alive,roomId,role?}`; roomId of other players must be null unless locally observable (spectator may see physical public positions), role ONLY after match. `self` is null for spectator, otherwise `{id,role,alive,roomId,tasks:[{id,label,roomId,completed}],cooldowns:{moveAt,taskAt,killAt,sabotageAt,meetingAt},meetingsRemaining}`. Self is not another player's info. `tasks:{completed,total}` is aggregate only. `sabotage` null or `{active,roomId,deadlineAt,repairsCompleted,repairsRequired}`. `meeting` null or `{id,calledBy,reason,bodyId,deadlineAt,messages:[{id,playerId,text,at}],votes:[{playerId,targetId?}],eligibleVoters:[ids]}`. Votes during voting reveal cast-status only; targets revealed after tally. `outcome` null or `{winner:'crew'|'saboteur',reason,at}`. `events` is bounded safe public timeline, no unseen killer, tasks, private role assignment or hidden actor metadata. `availableActions` is a list of permitted type names for UI hints; still server validate.

Rules doc MUST specify tie/no-vote/skip semantics, dead-task handling, initial cooldowns, meeting pauses vs critical countdown, emergency limit, missed deadlines, roam timeout and maximum-match behavior. Wins exactly tasks/ejection vs parity/critical. Do not invent a model-judged outcome. Prefer missed roam deadline to trigger meeting; max duration can pause transparently rather than manufacture winner.

## AI (Agent 3 / Reviewer explicit implementation assignment)

Own `server/ai/**`, `tests/ai*.test.mjs`, `docs/AI.md`. Export `createAiController({config})` from `server/ai/index.mjs`. It returns `async decide({view,player,context,signal})` => action envelope or null; `player` is public CHARACTERS entry, NEVER hidden engine object. `context` is serializable, private per-character/per-match AI memory + match budget; return mutations only within it, not in view. Same context object persists in each room as `aiContext`; separate memories keyed by match/player. Transport serializes proposed actions through engine. `describe(context)` returns safe `{mode,provider,model,calls,tokens,costUsd,limitReason?}` with no keys/reasoning/memory; include in room's safe view. Per-match budgets reserve before request (including parallel in-flight calls). Provider unavailable/budget exhausted explicitly switch to demo and append safe notices in context, exposed as room `notices`. Do not silently mislabel. Missing credentials defaults demo. `decide` must honor abort signal, timeout/retries, bounded prompt/output; no model calls every tick. At most one decision per actor per interval (transport schedules). Deterministic demo bots must finish games, cooperate, move/task/repair, report, debate, bluff and vote; only use own safe view. Use BFS deterministic movement. Live adapter chooses only structured allowed actions; use official provider documentation and retain links/date. No paid calls in tests. Root keys: config.ai = `{provider,apiKey,model,maxCalls,maxTokens,maxCostUsd,timeoutMs,decisionIntervalMs}`. Coordinator supplies config. Tell coordinator any required additions.

## Rooms/transport/persistence (Agent 5 / Integrations)

Own `server/rooms.mjs`, `server/transport.mjs`, `server/store.mjs`, `tests/transport*.test.mjs`, `docs/TRANSPORT.md`. Export `createGameServer(config)` from `server/transport.mjs` => `{server,close,rooms}`; server is unstarted native http.Server, close async cleans intervals/sockets/providers/storage. Coordinator launch calls server.listen(config.port,config.host). Import static fallback `serveStatic(req,res)` from `server/static.mjs`. Safe errors as `{error:{code,message}}`, never stack/hidden state. Body limit 8 KiB; same-origin APIs, validate origin on mutating routes + WS. HttpOnly SameSite cookies or equally strong server-side session auth; no secrets in URLs. Do not expose host token in public views. Preserve one human p1 only in human room; joiners spectators. Match continues when browsers leave: human misses discussion/vote=>abstains; during roam disconnect leaves seat idle, no reassignment. Only same seat may reconnect. Host browser unnecessary to progress started match. Bounded active rooms, creation/action/join/WS limits, expire ended/lobby rooms. Atomic persistence with validation/quarantine, serialize per-room state updates, restored request IDs and deadlines; restart must not duplicate actions/AI spend. Pending provider reservations persist before sending if live.

Routes: `GET /api/health`; `POST /api/rooms {mode:'human'|'spectator',name?}` creates host/identity and lobby, returns safe room view + roomId; `POST /api/rooms/:id/join` creates spectator cookie identity; `GET /api/rooms/:id` authenticated same-room view; `POST /api/rooms/:id/start {id}` host-only idempotent; `POST /api/rooms/:id/action` action envelope; `GET /api/rooms/:id/replay` ended only, room auth; `GET /api/rooms/:id/socket` WebSocket upgrade authenticated cookie. WS server messages `{type:'state',room:view}` / `{type:'error',error}`; client writes not required (HTTP actions). Public safe room envelope: `{roomId,mode,isHost,seatId,phase,connection,game,ai,notices,createdAt}`; lobby game null. `connection` can be simple status. game is engine view; never expose engine internal. AI prefill six characters automatically; start creates same engine for both modes. Start must be safe against simultaneous duplicate requests and cross-room seat cookies. Error statuses 400/401/403/404/409/429 as appropriate.

Configuration: `{host,port,dataDir,publicOrigin,maxActiveRooms,roomTtlMs,maxBodyBytes,ai,tickMs}`. Tests may inject fast rules via `config.rules` and test clock. No client rule overrides. `roomId` random safe identifier. `GET /api/health` includes no room IDs/secrets. Manager owns config/root; avoid imports not specified, send a message if contract needs correction.

## Frontend (Agent 4 / Frontend)

Own `public/**`, `tests/ui*.test.mjs`, `docs/UI.md`. Static entry `/`, modules import `/shared/contracts.mjs` if helpful. No build required; no CDN/external fonts/assets. UI uses exact routes/shape above, credentials same-origin, polls with backoff fallback if WS unavailable. `/r/:roomId` joins spectator when no cookie; persist only room ID/client action IDs, never role/private payload in localStorage. Fetch own view then join on401; do not auto-join repeatedly or overwrite human cookie. Abort/close old requests/sockets on room changes/dispose/hidden as appropriate; visibility resync current room. Create human/spectator, start lobby, map accessible room buttons, own role, legal tasks/repair/eliminate/report/emergency controls, timers and contextual feedback, discussion+voting skip, results and replay. Explain wins/rules in app. Spectator no private role. Fresh unique action IDs (crypto.randomUUID). Render dialogue with textContent, never HTML. Present demo/live mode and any fallback notice clearly. Mobile/desktop original restrained storm-beacon visual identity, readable, good focus/contrast/reduced motion. No model reasoning display.
