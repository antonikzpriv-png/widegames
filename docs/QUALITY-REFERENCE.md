# Gameplay reference and original design

Reviewed the primary [Innersloth game/how-to-play page](https://www.innersloth.com/games/among-us/) and its linked [card-task gameplay image](https://www.innersloth.com/wp-content/uploads/2021/06/CardSlideTask.png) on2026-10-30. The reference loop is free movement, local tasks, sabotage response, body/emergency reports, discussion/voting, information terminals and secret travel. Crew finishes tasks or ejects impostors; hostile players eliminate and deceive. The page describes4..15 players. It supplies no exact world-coordinate scale for us to certify; Lantern Wake therefore measures its own character-relative scale and travel times. Official images are private ignored references only, never bundled assets.

## Implemented original targets

Beacon2 is an original fourteen-room,3200x2400-unit storm-service ship with four linked decks, two service galleries, alternate crossings and isolated room purpose. Original Beacon1 and Annex1 remain permanent exact map versions. The normal walking speed remains180 units/s with a14-unit physical body radius. The map owner's196 station routes measure4.285..22.362s for nonzero travel; tested far-origin critical repair trips remain below17.891s before interaction, compared with75s critical deadlines. These are explicit route-length fixtures, not a proprietary scale measurement or a human-reaction guarantee.

Normal new watches assign four different room/kind station jobs per crew. Six original game puzzles use symbol circuits, frequency calibration, sequence records, glyph selection, rotor alignment and pressure-valve order. The nine-tile glyph inspection is CAPTCHA-like game equipment; it is not an external human-verification service. Both humans and demo robots use the same validated taskInteract inputs, progress and request receipts. Opening or submitting a client solved flag cannot complete them. Robots solve from their permitted clues through local logic; this is labeled demo/local behavior, never falsely described as paid model vision or independent evidence.

The visual target is a readable continuous game scene: room-specific equipment, deck material, trim, windows, pipework, raised collider-backed furniture, task panels and clear doors/interaction prompts. Static terrain uses a bounded tile cache and visible-region culling; moving entities, vision and actual availability stay live. Input and camera changes require reproducible collision/cadence controls plus native browser checks, not just new colors or unsupported FPS claims.

## Explicit differences retained

Lantern Wake retains its original raincoat keepers, storm-beacon setting, maps and source code. It does not copy Skeld geometry, characters, art, sounds, trademarks or all current optional roles. The normal roster is six with one saboteur; the existing server contract supports4..12 and multiple saboteurs. Public configurable multiplayer seating, ghosts/optional abilities and the full strategic planner remain Group2 seams until actually merged.

Existing discovery knowledge, dated owner-only investigation samples and full replay authorization stay as specified in TACTICAL-RULES.md. Unfinished work redistributes at council muster under the existing death policy; this phase does not silently change it into ghost gameplay. Current hybrid mode still uses live-provider council only, with local navigation/task policy and conservative unchanged budgets. No voice, ranking, monetization or paid-provider testing is added. These distinctions are documented instead of claiming exact parity with every Among Us system.
