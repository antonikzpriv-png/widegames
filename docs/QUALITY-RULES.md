# Gameplay-quality additions

Normal new rooms are version4, matches version5, with stationTasksVersion1 and the existing tacticalPreset. Storm Beacon2 has fourteen original rooms in a3200x2400 world; Stormbreak Annex1 retains its eight-room layout. Original Beacon1 remains a separate immutable exact version. World speed is180 units/s; measured station routes span approximately4.3..22.4 seconds. These are our world units and measured routes, not a claim of exact Among Us dimensions.

Each crew receives four different room/kind jobs. Circuit: connect equal symbols. Signal: set the displayed target frequency. Sequence: press the shown order. Glyph inspection: select every matching symbol and verify. Alignment: lock each rotor to its displayed bearing. Manifolds: open valves in ascending displayed pressure. The glyph grid is a short in-game CAPTCHA-like puzzle, not a third-party challenge/bypass. Demo bots derive proposed inputs from exactly their permitted clues. Inputs require living crew ownership, station proximity, line of sight, roam phase and no transit. Each step and accepted action receipt persists; wrong/duplicate input cannot skip work. The four-second task cooldown applies after full completion, not each step. A direct task action only opens new stations; legacy relay jobs retain direct completion.

Physics uses swept collision and a canonical direction lease path, so sparse/dense ticks cannot change the legal route around a corner. Rendering uses only permitted observations, collision-safe interpolation and at most100ms of own-input prediction. Snapshot-anchored camera easing is independent of render cadence. Hiding/closing revokes presentation and requests a best-effort stop; server leases retain their documented behavior if disconnected. Keyboard, touch joystick, click navigation, reduced motion and opt-in local sound remain.

All tactical rules remain in TACTICAL-RULES.md: local discovery-based death knowledge, server-enforced lights, comms, temporary doors, two-site critical failures, timed devices and saboteur-only maintenance passages. Meetings keep critical deadlines running, open doors and cancel passage travel. The default game is one human plus five bots or six bots, while the trusted roster API supports4..12 with validated factions. Public multiplayer seat selection, ghost gameplay and a full strategic planner are still Group2 extensions, not claimed implemented here.

Existing private rooms, HttpOnly identity cookies, accepted action IDs, replay permissions, spending reservations and provider settings remain. Restoring legacy versions does not silently opt them into new tasks/maps. Unsupported future versions fail closed without rewriting the original file. Always back up the entire stopped-service DATA_DIR before upgrading.
